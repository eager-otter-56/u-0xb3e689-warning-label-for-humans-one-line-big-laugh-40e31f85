# Warning Label for Humans: One Line, Big Laugh

A tiny Python program that prints the safety warning label that should
come printed on every human being. It writes a single line of text
(160 characters or fewer) to `entry.txt` in the directory named by the
`MAKEFUN_OUTPUT_DIR` environment variable (default `/output`).

The label, in classic printed-label wording:

> WARNING: May contain nuts. Needs eight hours of sleep, will take five and a grudge, and if this unit ever says 'I'm fine,' that is the malfunction talking.

Run it with:

```sh
python3 main.py
```
